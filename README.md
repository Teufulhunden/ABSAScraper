Purpose:
The purpose of this project is to scrape information from yelp and google business reviews and run it through an ABSA (Aspect Based Sentiment Analysis) Model. 
I am currently running this off of Omkar and SetFit (HF) ABSA. I intend to use pandas, SQLite 3, Streamlit, Google Gen-AI and others. I hope to run this program 
in congruence with business theory to gather and analyze data and use said data to create actionable reports.

Known Issues and Disclaimer:
This project is still in early development and is not yet useable. The pretrained model is weak and needs to be replaced by something stronger or trained from scratch.
The pricing for Omkar is some of the best in the industry for its quality but still runs slightly expensive.
